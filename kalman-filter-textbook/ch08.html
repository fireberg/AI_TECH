其他卡尔曼变体与应用场景速览

一、卡尔曼滤波家族

变体核心思想优点缺点典型应用
KF 线性系统 + 高斯噪声 最优解、计算简单 仅限线性系统 惯导预积分、温度滤波
EKF 一阶泰勒展开线性化 实现简单、计算可控 高度非线性时精度差 GPS/INS 融合、姿态估计

二、UKF——不用算雅可比的妙招

UKF（Unscented Kalman Filter）的核心思想是：与其线性化函数（EKF），不如直接用有代表性的采样点通过非线性函数，然后从输出重建统计量。

具体步骤：

  1. 生成 \(2n+1\) 个 Sigma 点：\(\chi_0 = \mu\)，\(\chi_i = \mu \pm \sqrt{(n+\lambda)P}\)
  2. 每个点通过非线性函数：\(\gamma_i = f(\chi_i)\)
  3. 从输出计算加权均值和协方差

📊 交互对比：EKF vs UKF

一个简单的非线性变换示例：高斯分布通过 \(y = x^2 + 0.2x^3\)。观察 EKF（线性化）和 UKF（sigma点）对输出分布的估计差异。

三、应用场景速览

电机转子位置估计

无传感器（Sensorless）电机控制：用反电动势观测器估计转子角度和转速，替代昂贵的编码器。

电压/电流 → 电机模型(EKF) → θ, ω
状态: [θ, ω, id, iq] | 更新率: 10~20kHz | 模型: 非线性(EKF)

无人机定高

融合气压计（慢但稳定）和加速度计（快但飘），估计海拔高度和垂直速度。

气压计 + IMU → KF 融合 → 高度, vz
状态: [h, vz, bias] | 更新率: 100Hz(IMU) + 25Hz(baro) | 线性 KF

扫地机器人 SLAM

同时定位与建图：用激光雷达或视觉构建环境地图，同时估计机器人位姿。EKF-SLAM 是早期经典方法。

LiDAR/视觉 → EKF-SLAM → 位姿 + 地图
状态: [x,y,θ,landmarks...] | 更新率: 5~30Hz | 状态维度可达 100+

电池 SOC 估计

通过电压和电流测量，估计电池荷电状态（State of Charge）。等效电路模型非线性，常用 EKF。

V, I → EKF + 电池模型 → SOC%
状态: [SOC, V_RC1, V_RC2] | 更新率: 1~10Hz | EKF/UKF

AHRS 姿态估计

融合陀螺仪、加速度计、磁力计估计 roll/pitch/yaw。Madgwick/Mahony 是简化版，完整版用 EKF/UKF。

9-axis IMU → EKF(四元数) → 姿态角
状态: [q0,q1,q2,q3,bias_gx,gy,gz] | 更新率: 200~1000Hz | 非线性

目标跟踪（雷达）

从雷达回波中跟踪飞行器或导弹的位置和速度。典型的多目标跟踪场景需要数据关联 + KF。

r,θ 测量 → 数据关联+EKF → 航迹
状态: [x,y,z,vx,vy,vz] | 更新率: 1~20Hz | Singer/IMM 模型

四、自适应卡尔曼滤波简介

标准 KF 假设 Q 和 R 是已知常数。但实际中噪声会变：GPS 在城市峡谷中精度急剧下降，电机在变速时过程噪声增大。

简单方法：基于新息的自适应

监测新息序列的实际方差，和理论方差 \(S = HPH^T + R\) 比较。如果实际方差明显大于理论值，说明 R 被低估了（或 Q 被低估了），动态调整：

$$\hat{R}_k = \frac{1}{W}\sum_{i=k-W+1}^{k} \nu_i \nu_i^T - HPH^T$$

信号在第 100 步时噪声突然增大 5 倍。观察固定参数 KF 和自适应 KF 的表现差异。

选型建议

  • 能用 KF 就用 KF（观测模型是线性的时候）
  • EKF 是 80% 场景的默认选择，雅可比手动推导一次后代码很简洁
  • UKF 适合"懒得推雅可比"或者非线性很强的场景，但内存开销约 2×
  • 粒子滤波适合多模态分布（机器人绑架问题），但不适合嵌入式实时场景
