第十章：误差分析——数学证明卡尔曼滤波为什么更准

从一个简单系统的误差出发，严格证明 KF 是最优线性无偏估计，并用交互实验亲眼看到精度提升

本章目标

  • 量化一个简单系统在"只用传感器"、"只用模型"、"简单平均"时的误差
  • 推导卡尔曼滤波的估计误差，证明它 严格小于 上述所有方法
  • 理解 KF 作为 最小方差无偏估计器 (MVUE) 的数学含义
  • 通过蒙特卡洛实验验证理论，建立"不是碰巧更好，而是数学上保证更好"的信心

一、问题设定——一个最简单的系统

为了让证明清晰，我们从最简单的一维静态系统出发。别觉得太简单——所有卡尔曼滤波的核心数学都已经蕴含在这个问题中了。

想象你要估计一个恒定的物理量 \(x\)（比如一个固定目标的距离），你有两个信息来源：

1 模型预测：你根据先验知识（上一时刻的估计、物理推算等），认为 \(x \approx \mu_p\)，不确定度为 \(\sigma_p\) $$\hat{x}_p = \mu_p, \quad \text{误差方差} = \sigma_p^2$$
2 传感器测量：传感器给出读数 \(z\)，含有零均值高斯噪声 $$z = x + v, \quad v \sim \mathcal{N}(0, \sigma_z^2)$$

问题：如何用 \(\hat{x}_p\) 和 \(z\) 两者构造一个估计 \(\hat{x}\)，使得估计误差的方差 \(E[(\hat{x} - x)^2]\) 最小？

二、四种估计策略的误差对比

我们来分析四种策略，看看它们的误差方差分别是多少。

策略 A：只相信传感器

$$\hat{x}_A = z$$ $$\text{MSE}_A = E[(z - x)^2] = E[v^2] = \sigma_z^2$$

误差完全由测量噪声决定。传感器差的时候，毫无办法。

策略 B：只相信模型

$$\hat{x}_B = \hat{x}_p$$ $$\text{MSE}_B = \sigma_p^2$$

误差完全由模型不确定度决定。如果模型很不确信，也毫无办法。

策略 C：简单平均

$$\hat{x}_C = \frac{1}{2}(\hat{x}_p + z)$$

推导策略 C 的误差方差

令 \(e_p = \hat{x}_p - x\)（预测误差），\(v = z - x\)（测量噪声），假设二者独立，则：

$$\hat{x}_C - x = \frac{1}{2}(e_p + v)$$ $$\text{MSE}_C = E\left[\left(\frac{e_p + v}{2}\right)^2\right] = \frac{1}{4}(\sigma_p^2 + \sigma_z^2)$$

简单平均确实比"只用一个"好（当两者方差相当时）。但它没有考虑两个来源的精度差异。如果传感器精度是模型的 10 倍，平均分配权重显然不聪明。

策略 D：卡尔曼滤波（最优加权）

$$\hat{x}_D = \hat{x}_p + K(z - \hat{x}_p) = (1-K)\hat{x}_p + K \cdot z$$

其中 \(K = \frac{\sigma_p^2}{\sigma_p^2 + \sigma_z^2}\) 是卡尔曼增益。

推导策略 D 的误差方差

$$\hat{x}_D - x = (1-K)e_p + Kv$$ $$\text{MSE}_D = (1-K)^2 \sigma_p^2 + K^2 \sigma_z^2$$

代入 \(K = \frac{\sigma_p^2}{\sigma_p^2 + \sigma_z^2}\)：

$$(1-K) = \frac{\sigma_z^2}{\sigma_p^2 + \sigma_z^2}$$ $$\text{MSE}_D = \frac{\sigma_z^4 \sigma_p^2 + \sigma_p^4 \sigma_z^2}{(\sigma_p^2 + \sigma_z^2)^2} = \frac{\sigma_p^2 \sigma_z^2(\sigma_z^2 + \sigma_p^2)}{(\sigma_p^2 + \sigma_z^2)^2} = \frac{\sigma_p^2 \sigma_z^2}{\sigma_p^2 + \sigma_z^2}$$

卡尔曼滤波的估计误差方差：

$$\boxed{\text{MSE}_{KF} = \frac{\sigma_p^2 \sigma_z^2}{\sigma_p^2 + \sigma_z^2} = \frac{1}{\frac{1}{\sigma_p^2} + \frac{1}{\sigma_z^2}}}$$

这就是两个电阻并联公式！融合后的"信息电阻"永远比任何一个单独的都小。

三、严格证明：KF 优于所有其他线性估计器

上面我们只是比较了四种具体策略。但 KF 真的是所有可能的线性组合中最好的吗？下面给出严格证明。

定理：最优线性无偏估计（BLUE / MVUE）

考虑所有形如 \(\hat{x} = (1-\alpha)\hat{x}_p + \alpha z\) 的线性无偏估计器（\(\alpha \in \mathbb{R}\) 为任意权重），卡尔曼增益 \(\alpha^* = K = \frac{\sigma_p^2}{\sigma_p^2 + \sigma_z^2}\) 使得 MSE 最小。

证明：

Step 1. 写出一般估计器的 MSE：

$$\text{MSE}(\alpha) = (1-\alpha)^2 \sigma_p^2 + \alpha^2 \sigma_z^2$$

Step 2. 对 \(\alpha\) 求导，令其为零：

$$\frac{d}{d\alpha}\text{MSE} = -2(1-\alpha)\sigma_p^2 + 2\alpha\sigma_z^2 = 0$$

Step 3. 解方程：

$$\alpha^* = \frac{\sigma_p^2}{\sigma_p^2 + \sigma_z^2} = K$$

Step 4. 二阶导 \(\frac{d^2}{d\alpha^2}\text{MSE} = 2(\sigma_p^2 + \sigma_z^2) > 0\)，确认为极小值。✓

Step 5. 代入 \(\alpha^*\) 得到最小 MSE：

$$\text{MSE}^* = \frac{\sigma_p^2 \sigma_z^2}{\sigma_p^2 + \sigma_z^2}$$

关键不等式

现在证明 KF 的 MSE 严格小于其他所有策略：

不等式证明

KF vs 只用传感器：

$$\frac{\sigma_p^2 \sigma_z^2}{\sigma_p^2 + \sigma_z^2} < \sigma_z^2 \iff \sigma_p^2 < \sigma_p^2 + \sigma_z^2 \quad \checkmark$$

KF vs 只用模型：

$$\frac{\sigma_p^2 \sigma_z^2}{\sigma_p^2 + \sigma_z^2} < \sigma_p^2 \iff \sigma_z^2 < \sigma_p^2 + \sigma_z^2 \quad \checkmark$$

KF vs 简单平均：

$$\frac{\sigma_p^2 \sigma_z^2}{\sigma_p^2 + \sigma_z^2} \leq \frac{\sigma_p^2 + \sigma_z^2}{4}$$

用 AM-HM 不等式：\(\frac{a+b}{2} \geq \frac{2}{\frac{1}{a}+\frac{1}{b}}\)，令 \(a=\sigma_p^2, b=\sigma_z^2\)：

$$\frac{\sigma_p^2+\sigma_z^2}{2} \geq \frac{2\sigma_p^2\sigma_z^2}{\sigma_p^2+\sigma_z^2}$$ $$\Rightarrow \frac{\sigma_p^2+\sigma_z^2}{4} \geq \frac{\sigma_p^2\sigma_z^2}{\sigma_p^2+\sigma_z^2} \quad \checkmark$$

等号当且仅当 \(\sigma_p = \sigma_z\)，此时卡尔曼增益 K=0.5 恰好退化为简单平均。

五、推广到多维动态系统

上面的一维静态案例让数学特别清晰。现在我们把结论推广到多维动态系统——也就是真正的卡尔曼滤波场景。

动态系统中的误差协方差

对于标准 KF 系统：

$$\mathbf{x}_{k+1} = \mathbf{F}\mathbf{x}_k + \mathbf{w}_k, \quad \mathbf{z}_k = \mathbf{H}\mathbf{x}_k + \mathbf{v}_k$$

定义估计误差 \(\mathbf{e}_k = \hat{\mathbf{x}}_k - \mathbf{x}_k\)，其协方差矩阵 \(\mathbf{P}_k = E[\mathbf{e}_k \mathbf{e}_k^T]\)。

定理：KF 更新后协方差严格减小

设预测后的协方差为 \(\mathbf{P}_{k|k-1}\)，更新后为 \(\mathbf{P}_{k|k}\)，则：

$$\mathbf{P}_{k|k} = (\mathbf{I} - \mathbf{K}_k\mathbf{H})\mathbf{P}_{k|k-1}$$

证明 \(\mathbf{P}_{k|k} \preceq \mathbf{P}_{k|k-1}\)（半正定序意义下）：

$$\mathbf{P}_{k|k-1} - \mathbf{P}_{k|k} = \mathbf{K}_k\mathbf{H}\mathbf{P}_{k|k-1} = \mathbf{K}_k \mathbf{S}_k \mathbf{K}_k^T$$

其中 \(\mathbf{S}_k = \mathbf{H}\mathbf{P}_{k|k-1}\mathbf{H}^T + \mathbf{R}\) 是新息协方差（正定矩阵）。

因此 \(\mathbf{K}_k \mathbf{S}_k \mathbf{K}_k^T\) 是半正定的 → \(\mathbf{P}_{k|k-1} - \mathbf{P}_{k|k} \succeq 0\) → 更新永远减小不确定度。✓

误差减小比例的精确量化

对于一维情况，上述结论给出精确的减小比例：

$$\frac{P_{k|k}}{P_{k|k-1}} = 1 - K = \frac{R}{P_{k|k-1} + R}$$

这意味着：

  • 如果 \(R \ll P_{k|k-1}\)（测量很准），则 \(P_{k|k} \approx R\) → 更新后不确定度接近测量噪声
  • 如果 \(R \gg P_{k|k-1}\)（测量很差），则 \(P_{k|k} \approx P_{k|k-1}\) → 更新几乎不改变估计
  • KF 总是自动选择最优的折中

定理：KF 是所有线性无偏估计器中的最优（BLUE）

对于线性高斯系统，卡尔曼滤波器产生的估计 \(\hat{\mathbf{x}}_{k|k}\) 满足：

  1. 无偏性：\(E[\hat{\mathbf{x}}_{k|k}] = E[\mathbf{x}_k]\)（估计均值等于真实均值）
  2. 最小方差：对于任何其他线性无偏估计器 \(\tilde{\mathbf{x}}_k\)，其误差协方差 \(\tilde{\mathbf{P}}_k\) 满足 \(\tilde{\mathbf{P}}_k - \mathbf{P}_{k|k} \succeq 0\)

证明思路（Gauss-Markov 定理的动态推广）：

任意线性无偏估计器可以写为 \(\tilde{\mathbf{x}} = \hat{\mathbf{x}}_{KF} + \mathbf{L}\boldsymbol{\nu}\)，其中 \(\boldsymbol{\nu}\) 是新息序列（白噪声），\(\mathbf{L}\) 是某个矩阵。无偏性要求 \(\mathbf{L}\) 满足特定约束，而 KF 对应 \(\mathbf{L}=0\)（最优增益已经提取了新息中所有信息）。任何非零 \(\mathbf{L}\) 只会增加方差。✓

七、信息论视角——为什么融合一定比单一来源好？

从信息论的角度，KF 的最优性有一个极其优美的解释。定义信息量（Fisher 信息）为方差的倒数：

$$\mathcal{I} = \frac{1}{\sigma^2}$$

那么 KF 的融合公式可以写为：

$$\mathcal{I}_{后验} = \mathcal{I}_{预测} + \mathcal{I}_{测量} = \frac{1}{\sigma_p^2} + \frac{1}{\sigma_z^2}$$

信息的可加性：融合 = 信息相加，信息只增不减

不管新传感器多差（\(\mathcal{I}_{测量}\) 多小），它只会增加总信息量 → MSE 只会减少。

这个性质的深刻含义是：

  • 加入一个精度为 10m 的 GPS，即使你已经有精度 0.1m 的激光雷达，理论上也会（微微）改善估计
  • 但实际中，如果传感器的噪声模型不准确（R 标定不对），坏数据反而会损害估计 → 这就是为什么需要异常值剔除

添加多个传感器，观察总信息量（= 1/MSE）如何随着传感器数量增加而增长，MSE 如何单调下降。

八、精度提升的极限——Cramér-Rao 下界

KF 的误差能无限小吗？当然不能。Cramér-Rao 下界 (CRLB) 给出了任何无偏估计器能达到的最小方差：

$$\text{MSE} \geq \frac{1}{\mathcal{I}_{Fisher}}$$

对于线性高斯系统，KF 恰好达到这个下界——这就是"最优"的精确含义。没有任何无偏估计器能做得更好，不管你多聪明。

但请注意限制条件：

条件满足时不满足时
线性系统KF 是精确最优EKF 是近似最优，可能不达到 CRLB
高斯噪声KF 是精确最优KF 是最优线性估计器，但非线性估计器可能更好
模型准确KF 是精确最优KF 会有系统偏差（模型失配）
Q/R 已知KF 是精确最优需要自适应 KF 或在线参数估计

嵌入式开发者笔记

从理论到实践的鸿沟

数学证明了 KF 在理想条件下是最优的。但在真实嵌入式系统中，以下因素会导致实际误差大于理论值：

  • 模型失配：真实系统不完全是线性的，F 矩阵是近似。解法：用 EKF/UKF，或增加状态维度
  • 噪声非高斯：GPS 在城市峡谷有多路径误差（重尾分布）。解法：鲁棒 KF 或马氏距离门限
  • Q/R 标定不准：这是实践中最常见的问题。解法：用 NIS 检验在线调参（见第七章）
  • 数值误差：有限字长导致 P 矩阵失去正定性。解法：Joseph 形式或 UD 分解
